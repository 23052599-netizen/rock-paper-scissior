# ✊✋✌ Rock Paper Scissors Game

A simple and interactive Rock-Paper-Scissors game built using **HTML**, **CSS**, and **JavaScript**. Players can compete against the computer, and scores are tracked in real-time.

## 🎯 Game Rules

1. Rock beats Scissors
2. Scissors beats Paper
3. Paper beats Rock
4. Same choices result in a Draw

## 📖 How to Play

1. Click on Rock, Paper, or Scissors.
2. The computer will generate a random choice.
3. The result will be displayed instantly.
4. Scores update automatically.
